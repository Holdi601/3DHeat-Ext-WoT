# Документ меча {#the-match-document}

`<match>.match.json` држи све што реплеј каже, а што није ред табеле. Картица
приказача Меч чита њега. (Код га зове резиме.)

![Почетак синтетичког документа меча, и његови кључеви](../assets/img/match-document.svg)

## Битка {#the-battle}

| Кључ | Шта је |
|---|---|
| `format`, `version` | `heat3d-wot-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Tanks`; ид битке; ид мапе и њено приказно име |
| `clientVersion`, `streamVersion` | верзија игре из заглавља, и како је каже низ пакета |
| `recorded` | када је реплеј снимљен, како га игра записује |
| `player`, `vehicle` | снимајући играч и његов тенк |
| `battleType`, `gameplay`, `server`, `region`, `hasMods` | број типа битке из заглавља, режим игре, сервер, регион, и да ли су модови били инсталирани |
| `duration` | дужина битке у секундама, из резултата |
| `winnerTeam`, `finishReason` | победнички тим и игрин број за то како је битка завршена, из резултата |
| `complete`, `truncated` | резултати су у реплеју; снимање је стало рано |
| `battleStart`, `battleStartFrom`, `firstMovement` | почетак битке у секундама снимања; `arena` (арена је то рекла) или `movement` (први тренутак кад се неки тенк померио); тај први покрет |
| `recordingSeconds` | дужина снимања у секундама |
| `positionPacket`, `hz`, `positions` | број пакета у ком су стигле позиције, узорци у секунди, редови позиција |
| `events` | број редова табеле за сваки догађај |
| `units` | `metres; x east, y up, z north` (метри; x исток, y горе, z север) |
| `decoded` | бројеви метода и пакета нађени за сваку врсту поруке |

## Играчи и догађаји {#players-and-events}

| Кључ | Шта је |
|---|---|
| `players` | један унос по тенку: име, тим, тенк, клан, узорци, убиства, нанета штета, преживео, време живота; `seen` (пуцњи и штета које је снимајући клијент видео); цео унос из заглавља и резултата, и налог |
| `kills` | свака смрт: време (секунде), одакле је време дошло (`arena`, `health` или `lifeTime`), жртва, убица, број и име разлога |
| `periods` | периоди битке (чекање, пре битке, битка, после битке) с крајњим временима сервера |
| `basePoints` | напредак заузимања база по тиму и бази |
| `chat`, `commands` | редови ћаскања; команде битког ћаскања са свим аргументима |
| `camera`, `clientEvents` | режими камере снимајућег играча; оно што је клијент забележио о себи (зум, аутоматско нишањење, промене мете, стање возила) |
| `arenaUpdates` | свако ажурирање арене, декодирано, онако како га је игра послала |

## Резултати и провере {#results-and-checks}

| Кључ | Шта је |
|---|---|
| `serverSettings` | подешавања сервера из заглавља |
| `results`, `resultVehicles`, `frags` | екран резултата: заједничко, лично (с појединостима по мети), играчи, налози; ред резултата сваког тенка; убиства по играчу |
| `entities` | сваки ентитет који низ ствара: његов број типа и улога, када је ушао у поглед клијента и када га је напустио |
| `selfCheck` | бројање потпуности ([Потпуност](completeness.md)) и провере ентитета и верзије |
