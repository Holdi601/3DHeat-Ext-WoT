# Преобразование реплеев {#converting-replays}

## Пошагово {#step-by-step}

1. **Включите запись в игре:** Настройки > Общие > Записывать бои. С этого момента игра
   сохраняет каждый бой в папку `replays` вашей установки World of Tanks, например
   `C:\Games\World_of_Tanks_EU\replays`.
2. **Откройте терминал** в папке, куда могут попасть результаты
   ([Перед началом](before-you-start.md)).
3. **Запустите преобразователь** на файлах реплеев или на папках, которые их содержат:

   ```bash
   heat3d-wot-replay "C:\Games\World_of_Tanks_EU\replays" -o out
   heat3d-wot-replay a.wotreplay b.wotreplay -o out
   ```

   Папка `out` создаётся в папке, где открыт ваш терминал.
4. **Прочитайте, что написано в выводе.** На каждый реплей должна быть одна строка,
   которая заканчивается таблицей, которую он записал.
5. **Откройте результат** в просмотрщике 3DHeat: `out/<map>/<match>.parquet` на вкладке
   «Тепловая карта», `<match>.match.json` на вкладке «Матч». Или прочитайте их любой
   программой для Parquet или JSON.

![Запуск на синтетическом реплее: преобразование, повторный запуск, испорченный файл, пустая папка](../assets/img/convert.svg)

Картинка показывает запуск на реплее, который строят тесты в коде (настоящего реплея нет):

- реплей преобразован: `<file>: <n> positions of <n> vehicles at <rate> Hz, <n> deaths, <map> (<client version>) -> <table>`;
- запуск повторно: матч, который уже записан, пропускается: `<file>: already written, <table>`;
- файл, который не является реплеем: `<file>: not converted: <why>` (в потоке ошибок; код
  завершения 1, остальные реплеи всё равно преобразуются);
- реплей не найден: `no .wotreplay files in <folders>` (код завершения 2).

## Параметры {#options}

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `replays` (один или несколько) | - | файлы `.wotreplay` или папки, в которых их ищут (включая подпапки) |
| `-o`, `--out` | обязательный | папка, куда писать: внутри создаётся папка на каждую карту |
| `--force` | выключен | преобразовать заново то, что уже записано |
| `--version` | - | вывести `heat3d-wot-replay <version>` и остановиться |
| `-h`, `--help` | - | вывести параметры и остановиться |

Параметры в том виде, как их выводит программа: [Справка по командам](../cli-reference.md).

## Что записывается {#what-is-written}

Только отдельные файлы: этот преобразователь не записывает файл `.3dheat` (просмотрщик может
упаковать их в один: [Один файл на матч](https://holdi601.github.io/3DHeat/container.html)).
На каждый реплей в `out/<map>/` записываются:

| Файл | Что в нём |
|---|---|
| `<match>.parquet` | таблица: позиция каждого танка во времени и каждое событие, где оно произошло ([Таблица](table.md)) |
| `<match>.match.json` | документ матча: карта, версия клиента, игроки, убийства, результаты и всё остальное ([Документ матча](match-document.md)) |
| `<match>.messages.parquet` | вспомогательный файл: каждый элемент реплея, который два файла выше не содержат целиком ([Полнота](completeness.md)) |

`<match>` — это собственный id боя или имя файла, если запись остановилась до результатов.

## Код завершения {#exit-status}

`0`, когда каждый реплей преобразован или пропущен, `1`, когда какой-либо не удалось (остальные
всё равно преобразуются), `2`, когда ни одного файла реплея не найдено.
