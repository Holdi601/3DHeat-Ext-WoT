# Дакумент матча {#the-match-document}

`<match>.match.json` трымае ўсё, што кажа запіс і што не з'яўляецца радком
табліцы. Яго чытае ўкладка «Матч» праглядальніка. (У кодзе ён называецца summary.)

![Пачатак сінтэтычнага дакумента матча і яго ключы](../assets/img/match-document.svg)

## Бой {#the-battle}

| Ключ | Што |
|---|---|
| `format`, `version` | `heat3d-wot-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Tanks`; id бою; id карты і яе паказная назва |
| `clientVersion`, `streamVersion` | версія гульні з загалоўка і яна ж, як яе называе струмень пакетаў |
| `recorded` | калі запіс быў зроблены, як яго піша гульня |
| `player`, `vehicle` | гулец, які вёў запіс, і яго танк |
| `battleType`, `gameplay`, `server`, `region`, `hasMods` | нумар тыпу бою з загалоўка, рэжым гульні, сервер, рэгіён і ці былі ўсталяваны моды |
| `duration` | працягласць бою ў секундах, з вынікаў |
| `winnerTeam`, `finishReason` | каманда-пераможца і нумар гульні, як скончыўся бой, з вынікаў |
| `complete`, `truncated` | вынікі ёсць у запісе; запіс спыніўся раней |
| `battleStart`, `battleStartFrom`, `firstMovement` | пачатак бою ў секундах запісу; `arena` (так сказала арэна) або `movement` (першы момант, калі рухаўся якой-небудзь танк); гэты першы рух |
| `recordingSeconds` | працягласць запісу ў секундах |
| `positionPacket`, `hz`, `positions` | нумар пакета, у якім прыйшлі пазіцыі, адлікаў у секунду, радкі пазіцый |
| `events` | колькасць радкоў табліцы кожнай падзеі |
| `units` | `metres; x east, y up, z north` |
| `decoded` | знойдзеныя нумары метадаў і пакетаў для кожнага віду паведамленняў |

## Гульцы і падзеі {#players-and-events}

| Ключ | Што |
|---|---|
| `players` | запіс на танк: імя, каманда, танк, клан, адлікі, забойствы, нанесены ўрон, выжыў, час жыцця; `seen` (стрэлы і ўрон, якія бачыў кліент, што вёў запіс); цэлы запіс загалоўка і вынікаў і запіс акаўнта |
| `kills` | кожная смерць: час (секунды), адкуль узяты час (`arena`, `health` або `lifeTime`), ахвяра, забойца, нумар і назва прычыны |
| `periods` | перыяды бою (чаканне, перад боем, бой, пасля бою) з часам завяршэння ад сервера |
| `basePoints` | ход захопу базы па камандзе і базе |
| `chat`, `commands` | радкі чата; каманды баявога чата з усімі аргументамі |
| `camera`, `clientEvents` | рэжымы камеры гульца, які вёў запіс; што кліент запісаў пра сябе (маштаб, аўтапрыцэл, змены мэты, стан машыны) |
| `arenaUpdates` | кожнае абнаўленне арэны, дэкадаванае, як дасланае гульнёй |

## Вынікі і праверкі {#results-and-checks}

| Ключ | Што |
|---|---|
| `serverSettings` | налады сервера з загалоўка |
| `results`, `resultVehicles`, `frags` | экран вынікаў: агульныя, асабістыя (з падрабязнасцямі па мэтах), гульцы, акаўнты; радок вынікаў кожнага танка; забойствы па гульцах |
| `entities` | кожная сутнасць, якую стварае струмень: яе нумар тыпу і роля, калі яна ўвайшла ў поле зроку кліента і калі выйшла |
| `selfCheck` | лічба паўнаты ([Паўната](completeness.md)) і праверкі сутнасцей і версіі |
