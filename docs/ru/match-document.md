# Документ матча {#the-match-document}

`<match>.match.json` содержит всё, что говорит реплей и что не является строкой таблицы.
Вкладка «Матч» просмотрщика читает именно этот файл. (В коде он называется summary, сводка.)

![Начало синтетического документа матча и его ключи](../assets/img/match-document.svg)

## Бой {#the-battle}

| Ключ | Что |
|---|---|
| `format`, `version` | `heat3d-wot-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Tanks`; id боя; id карты и её отображаемое название |
| `clientVersion`, `streamVersion` | версия игры из заголовка и та, которую говорит поток пакетов |
| `recorded` | когда был записан реплей, как его записывает игра |
| `player`, `vehicle` | игрок, который записал реплей, и его танк |
| `battleType`, `gameplay`, `server`, `region`, `hasMods` | номер типа боя из заголовка, игровой режим, сервер, регион и установлены ли моды |
| `duration` | длительность боя в секундах, по результатам |
| `winnerTeam`, `finishReason` | победившая команда и номер игры для причины окончания боя, по результатам |
| `complete`, `truncated` | результаты есть в реплее; запись остановилась раньше |
| `battleStart`, `battleStartFrom`, `firstMovement` | начало боя в секундах записи; `arena` (так сказала арена) или `movement` (первый момент, когда двинулся любой танк); этот первый ход |
| `recordingSeconds` | длительность записи в секундах |
| `positionPacket`, `hz`, `positions` | номер пакета, в котором пришли положения, выборок в секунду, строки положений |
| `events` | количество строк таблицы каждого события |
| `units` | `metres; x east, y up, z north` |
| `decoded` | номера методов и пакетов, найденные для каждого вида сообщений |

## Игроки и события {#players-and-events}

| Ключ | Что |
|---|---|
| `players` | одна запись на танк: имя, команда, танк, клан, выборки, убийства, нанесённый урон, выжил ли, время жизни; `seen` (выстрелы и урон, которые увидел записывавший клиент); полная запись из заголовка и из результатов, и аккаунт |
| `kills` | каждая смерть: время (секунды), откуда взято время (`arena`, `health` или `lifeTime`), жертва, убийца, номер и название причины |
| `periods` | периоды боя (ожидание, предбоевой, бой, послебоевой) с временем окончания от сервера |
| `basePoints` | прогресс захвата базы по командам и базам |
| `chat`, `commands` | строки чата; команды боевого чата со всеми их аргументами |
| `camera`, `clientEvents` | режимы камеры игрока, который записал реплей; что записал клиент о себе (приближение, автоприцеливание, смены цели, состояние техники) |
| `arenaUpdates` | каждое обновление арены, прочитанное, как его прислала игра |

## Результаты и проверки {#results-and-checks}

| Ключ | Что |
|---|---|
| `serverSettings` | настройки сервера из заголовка |
| `results`, `resultVehicles`, `frags` | экран результатов: общие, личные (с подробностями по каждой цели), игроки, аккаунты; строка результатов каждого танка; убийства по игрокам |
| `entities` | каждая сущность, которую создаёт поток: её номер типа и роль, когда она появилась в поле зрения клиента и когда ушла |
| `selfCheck` | подсчёт полноты ([Полнота](completeness.md)) и проверки сущностей и версии |
