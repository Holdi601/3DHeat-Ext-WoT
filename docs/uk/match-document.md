# Документ матчу {#the-match-document}

`<match>.match.json` містить усе, що повтор розповідає і що не є рядком таблиці.
Вкладка «Матч» переглядача читає саме його. (У коді його називають підсумком.)

![Початок синтетичного документа матчу і його ключі](../assets/img/match-document.svg)

## Бій {#the-battle}

| Ключ | Що це |
|---|---|
| `format`, `version` | `heat3d-wot-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Tanks`; ідентифікатор бою; ідентифікатор карти і її назва для показу |
| `clientVersion`, `streamVersion` | версія гри із заголовка і та, що каже потік пакетів |
| `recorded` | коли записано повтор, як це записує гра |
| `player`, `vehicle` | гравець, що записав повтор, і його танк |
| `battleType`, `gameplay`, `server`, `region`, `hasMods` | номер типу бою із заголовка, режим гри, сервер, регіон і чи були встановлені модифікації |
| `duration` | тривалість бою в секундах, з результатів |
| `winnerTeam`, `finishReason` | команда-переможець і номер, яким гра позначає, як закінчився бій, з результатів |
| `complete`, `truncated` | результати є в повторі; запис зупинився раніше |
| `battleStart`, `battleStartFrom`, `firstMovement` | початок бою в секундах запису; `arena` (арена так сказала) або `movement` (перший момент, коли хоч один танк рушив); цей перший рух |
| `recordingSeconds` | тривалість запису в секундах |
| `positionPacket`, `hz`, `positions` | номер пакета, у якому прийшли положення; відліків на секунду; рядки положень |
| `events` | кількість рядків таблиці кожної події |
| `units` | `metres; x east, y up, z north` (метри; x — схід, y — вгору, z — північ) |
| `decoded` | номери методів і пакетів, знайдені для кожного виду повідомлень |

## Гравці і події {#players-and-events}

| Ключ | Що це |
|---|---|
| `players` | один запис на танк: назва, команда, танк, клан, відліки, вбивства, завдана шкода, чи вижив, час життя; `seen` (постріли і шкода, які бачив клієнт, що записав повтор); повний запис із заголовка і з результатів, і облікового запису |
| `kills` | кожна смерть: час (секунди), звідки взято час (`arena`, `health` або `lifeTime`), жертва, вбивця, номер і назва причини |
| `periods` | періоди бою (очікування, передбій, бій, після бою) з часом завершення від сервера |
| `basePoints` | прогрес захоплення бази для кожної команди і кожної бази |
| `chat`, `commands` | рядки чату; команди чату бою з усіма їхніми аргументами |
| `camera`, `clientEvents` | режими камери гравця, що записав повтор; що клієнт записав про себе (масштаб, автонаведення, зміни цілі, стан техніки) |
| `arenaUpdates` | кожне оновлення арени, декодоване, як його надіслала гра |

## Результати і перевірки {#results-and-checks}

| Ключ | Що це |
|---|---|
| `serverSettings` | налаштування сервера із заголовка |
| `results`, `resultVehicles`, `frags` | екран результатів: загальні, особисті (з подробицями по цілях), гравці, облікові записи; рядок результатів кожного танка; вбивства на гравця |
| `entities` | кожна сутність, яку створює потік: її номер типу і роль, коли вона з'явилася в полі зору клієнта і коли зникла |
| `selfCheck` | лічильник повноти ([Повнота](completeness.md)) і перевірки сутностей та версії |
