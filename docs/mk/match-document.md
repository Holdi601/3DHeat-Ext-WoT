# Документот за мечот {#the-match-document}

`<match>.match.json` содржи сè што го кажува снимката, а не е ред од табелата. Табот Меч на прегледувачот го чита. (Кодот го вика summary.)

![Почетокот на синтетички документ за меч и неговите клучеви](../assets/img/match-document.svg)

## Битката {#the-battle}

| Клуч | Што |
|---|---|
| `format`, `version` | `heat3d-wot-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Tanks`; идот на битката; идот на мапата и нејзиното име за приказ |
| `clientVersion`, `streamVersion` | верзијата на играта од заглавието, и како ја кажува текот на пакети |
| `recorded` | кога е снимена снимката, како што го пишува играта |
| `player`, `vehicle` | снимачкиот играч и неговиот тенк |
| `battleType`, `gameplay`, `server`, `region`, `hasMods` | бројот на типот битка од заглавието, режимот на играта, серверот, регионот, и дали биле инсталирани модови |
| `duration` | должината на битката во секунди, од резултатите |
| `winnerTeam`, `finishReason` | победничкиот тим и бројот на играта за тоа како завршила битката, од резултатите |
| `complete`, `truncated` | резултатите се во снимката; снимањето запрело предвреме |
| `battleStart`, `battleStartFrom`, `firstMovement` | почетокот на битката во секунди од снимањето; `arena` (арената го кажала) или `movement` (првиот момент кога се движел кој и да е тенк); тоа прво движење |
| `recordingSeconds` | должината на снимањето во секунди |
| `positionPacket`, `hz`, `positions` | бројот на пакетот во кој дошле позициите, примероци во секунда, редови на позиции |
| `events` | бројот на редови на табелата од секој настан |
| `units` | `metres; x east, y up, z north` |
| `decoded` | методот и броевите на пакети најдени за секој вид порака |

## Играчи и настани {#players-and-events}

| Клуч | Што |
|---|---|
| `players` | една ставка по тенк: име, тим, тенк, клан, примероци, убиства, нанесена штета, преживеал, време на живот; `seen` (истрелите и штетата што ги видел клиентот што снимал); целата ставка од заглавието и од резултатите, и онаа на профилот |
| `kills` | секоја смрт: време (секунди), од каде дошло времето (`arena`, `health` или `lifeTime`), жртва, убиец, број и име на причината |
| `periods` | периодите на битката (чекање, предбитка, битка, побитка) со крајните времиња од серверот |
| `basePoints` | напредок на заземање на база по тим и база |
| `chat`, `commands` | линии од разговор; команди од разговорот во битка со сите нивни аргументи |
| `camera`, `clientEvents` | режимите на камерата на снимачкиот играч; што клиентот забележал за себе (зум, автоматско целење, промени на цел, состојба на возилото) |
| `arenaUpdates` | секое ажурирање на арената, декодирано, како што го пратила играта |

## Резултати и проверки {#results-and-checks}

| Клуч | Што |
|---|---|
| `serverSettings` | поставките на серверот од заглавието |
| `results`, `resultVehicles`, `frags` | екранот со резултати: општо, лично (со детали по цел), играчи, профили; линијата со резултати на секој тенк; убиства по играч |
| `entities` | секој ентитет што го создава текот: неговиот број на тип и улога, кога влегол во погледот на клиентот и кога излегол |
| `selfCheck` | бројката за комплетност ([Комплетност](completeness.md)) и проверките на ентитетите и верзијата |
